## 隐私规则

- 照片、裁剪图、遮罩、候选形象、生成关键姿势和逐帧预览只保存在 `E:\PetForge\evaluations` 或用户选择的本地目录。
- GitHub、CI、公开截图与测试夹具中不放真人照片、姓名、原图路径、提示词、EXIF 或未经同意的角色图。
- 每位真人必须单独确认照片处理同意；角色是否被本人接受也必须单独记录。照片授权不等于允许公开发布。
- 本表只填写随机案例 ID、技术指标和经审核的结果。不要填写真实姓名、账号、绝对路径、令牌或密钥。

逐阶段耗时和资源数据由本地 `p0-eval-evidence.json` 生成。不要将照片文件路径复制进公开记录。

照片生成后，先检查候选角色，再明确接受或拒绝已有候选。复核只移动和记录现有本机文件，不会重新生成角色：

```powershell
petforge-worker review-candidate --candidate-dir <本地候选目录> --decision accept
petforge-worker review-candidate --candidate-dir <本地候选目录> --decision reject
```

接受后，候选进入本机 `revisions/` 并更新 `accepted.json`；拒绝后完整保留在 `rejected/`。只有接受的角色才计入角色审核门槛。

需要微调骨架时，可在本机重新预览并传入一个或多个关节点偏移。偏移以画布宽高比例表示，单轴最大 `0.05`：

```powershell
petforge-worker preview-actions --candidate-dir <本地候选目录> --correction left_wrist=0.02,-0.01
```

动作清单会记录被调整的关节点及偏移值。原始检测点保留在候选的 `candidate-pose.json` 中。

## 结论

- **pass**：达到样本覆盖、两位角色接受、十项动作审核、CPU 参考机与支持 GPU 的全部门槛，且没有未处理失败。
- **incomplete_samples**：没有失败证据，但缺样本、本人审核、CPU/GPU 或动作审核证据。
- **fail**：人物流程、隐私、模型许可、文件校验或生成/动作结果存在失败证据。修复后重新评估，不得通过删除失败记录来变成 `pass`。
